# 馬育成シューティング（Horse Training Shooter）

C++ / SFML で開発した自主制作ゲームです。提出物として、研究成果に添えるプログラム作品という位置づけで制作しました。

## 制作意図

自分の趣味である競馬をモチーフに、競馬・育成ゲームが好きな人に刺さるテーマのゲームを作りたいと考え、攻撃ではなく育成という切り口のシューティングゲームを企画しました。プレイヤーは調教師として、食糧・良い環境・愛情・しつけという4種の育成アクションを馬に当てて能力を伸ばします。育成というポジティブな行為をゲームに落とし込むことで、自分自身が楽しみながら開発を続けられるテーマにすることを重視しました。また、この育成によって自分だけの能力を持った馬をレースで走らせることができるような選択肢も今後の方針として構想しております。

## 遊び方

| 操作 | 内容 |
|---|---|
| `W` `A` `S` `D` | 自機（調教師）の移動 |
| `1` `2` `3` `4` | 育成アクションの選択（1:食糧／2:良い環境／3:愛情／4:しつけ） |
| `Space` | 選択中の育成アクションを発射 |
| `R` | 制限時間になり，結果画面後のリスタート |

起動すると即座にプレイが始まります。

制限時間以内に、選んだ育成アクションを画面上部にいる馬に当てて「総合能力」を表すスコアを伸ばすタイムアタック形式です。馬はスコアに応じて移動速度が上がっていくことで，成長していることを表しています。今回は60秒の制限時間としています。

## 動作環境

- Windows 10/11
- 実行に追加のインストールは不要

## 技術構成・工夫した点

- 言語：C++17
- グラフィックス・入力：SFML 3.0.2
- 自機の移動に慣性によるふわふわ感を実装するため、摩擦と加速度を搭載
- 育成アクションごとの発射クールダウン・連射／単発の性質を`enum class`と`std::array`のテーブルで管理し、`switch`文の羅列を避けている
- 育成アクションは1〜4キーで選択してからSpaceで発射する方式にし、食糧や愛情といったアクションは選択を維持したまま連打でき、環境やしつけといったアクションはあえて毎回選び直しが必要になるようにすることで、重さや価値の差別を行いました

## 今後の実装予定

締切に合わせて設計範囲を絞ったため、以下は構想のみとなっており、実装には至っておりません。

- タイトル画面
- 育成アクションの種類ごとにスコア加算量を変えることで価値をさらに区別
- 馬のサイズがスコアに応じて視覚的に大きくなるようにし，成長を可視化
- 育成アクションによって加算される能力を細かく分け，育成が終わった馬の情報を保存し，自分だけの育成結果となるようにする
